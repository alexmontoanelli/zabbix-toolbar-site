---
title: Alerts and sounds
description: Choose which severities notify you and which sound each one plays.
order: 4
---

Open **Settings → General → Alerts**. For each severity — Disaster, High, Average, Warning, Information and Not classified — choose:

- **Notification**: whether new problems of this severity show a macOS notification.
- **Sound**: which system sound plays, or **None**.

These settings apply to new problems from all servers. When several new problems arrive in the same poll, a single sound plays: the one for the highest severity.

Alerts per severity are part of Pro. On the **Free** plan you get notifications for all severities, with no sound.

To filter problems out entirely instead of just silencing them, use a [minimum severity](/docs/servers/#minimum-severity) on the server.
